# Verruculogen cluster RNA-seq: *P. brasilianum* co-cultured with *B. subtilis* DK1042 WT vs Δ*dhbF*

Analysis code for the co-culture RNA-seq experiment reported in the accompanying
paper, which asks whether the siderophore **bacillibactin** represses fungal
secondary metabolism.

*Penicillium brasilianum* SFC20200506-M13 was co-cultured on potato dextrose agar
with *Bacillus subtilis* DK1042 — the naturally competent *comI*<sup>Q12L</sup>
derivative of NCIB 3610 — or with its Δ*dhbF* mutant in the same background,
which cannot assemble bacillibactin but still produces the precursor
2,3-dihydroxybenzoate. The bacterial partner is the only difference between the
two conditions, so the contrast isolates the effect of bacillibactin on the
fungus.

**Result.** All eight genes of the verruculogen (fumitremorgin) biosynthetic
cluster, *ftmA*–*ftmH*, are lower when the bacillibactin-producing wild type is
present, by 25- to 315-fold. The largest change is in *ftmF*, the
Fe(II)/α-ketoglutarate-dependent dioxygenase that converts fumitremorgin B into
verruculogen and the only iron-dependent enzyme of the pathway. A cluster-level
rotation test gives *P* = 0.024 with all eight genes moving downward.

## Which libraries this analyses

Six libraries were sequenced, three per condition. **This repository analyses
four of them** — the design reported in the paper — and the count tables
distributed here are those four:

| Sample | Group | Co-culture partner | Reads mapping to the fungal genome |
|---|---|---|---|
| 3610-1 | treatment | *B. subtilis* DK1042 wild type | 57.8 % |
| 3610-2 | treatment | *B. subtilis* DK1042 wild type | 77.8 % |
| KO-1 | control | *B. subtilis* DK1042 Δ*dhbF* | 19.3 % |
| KO-3 | control | *B. subtilis* DK1042 Δ*dhbF* | 18.6 % |

The two excluded libraries were atypical for their group:

- **3610-5** — only 35.6 % of its reads map to the fungal genome, against 57.8 %
  and 77.8 % for the other two wild-type libraries, and its correlation with the
  knock-out group is nearly as high as its correlation with its own group
  (separation 0.043, against 0.127 and 0.154 for the other two).
- **KO-2** — 39.5 % of its reads map to the fungal genome, roughly twice the
  18.6 % and 19.3 % of the other two knock-out libraries.

**All six sequenced libraries, including the two excluded here, are deposited in
the NCBI SRA** under the BioProject given in `data/README.md`, so the exclusion
can be checked and the analysis repeated on any subset.

```
  config.R           paths, sample table, the design, thresholds, palette
  config.py          the same, for the Python steps

  01_differential_expression/run_de.R
  02_geneset_analysis/geneset_tests.R
  03_qc/             fungal read fraction, expression-filter sensitivity
  04_figures/        the manuscript volcano plot
results/             everything below is regenerated by the scripts
env/                 package installation and the recorded session info
submission/          NCBI SRA submission metadata for all six libraries
```

No script contains an absolute path. `scripts/config.R` and `scripts/config.py`
locate the repository root by walking up from the script's own location to the
`.repo-root` marker, so the code runs from any working directory. Set
`PBRAS_ROOT` to override.

## Running it

```bash
Rscript env/install.R                  # limma, edgeR, ggplot2, ggrepel, dplyr
pip install -r env/requirements.txt

Rscript scripts/01_differential_expression/run_de.R    # differential expression
Rscript scripts/02_geneset_analysis/geneset_tests.R    # cluster-level tests
Rscript scripts/03_qc/qc_bacterial_load.R              # the fungal read fraction
Rscript scripts/03_qc/filter_sensitivity.R             # expression filter
Rscript scripts/04_figures/volcano_labstyle.R d22a fdr 2.5   # manuscript figure
```

The whole chain takes about a minute. Starting from the raw reads instead
requires `scripts/00_quantification/kallisto_quant.py` and the reference genome;
see `data/README.md`.

## Method

Counts → `readDGE` → keep genes with `rowSums(cpm > 1) >= 3` → TMM normalisation
→ `voom` → `lmFit` → `contrasts.fit` → `treat(lfc = 1)` → `topTreat`.
8,831 of the 11,432 annotated genes pass the expression filter.

The contrast is `treatment − control` = (co-culture with DK1042 wild type) −
(co-culture with Δ*dhbF*), so **a negative log₂FC means the gene is lower when
bacillibactin is present**. `treat(lfc = 1)` tests the compound null hypothesis
|log₂FC| ≤ 1 rather than log₂FC = 0, which is more conservative than the usual
`eBayes` test; both are written out by `run_de.R`.

**Two different thresholds appear here and they are not the same thing.**
`treat(lfc = 1)` asks whether a gene's true effect exceeds **2-fold**; that is
what produces every *P* value and FDR in the tables. The volcano plot
additionally shades points at |log₂FC| ≥ 2, i.e. **4-fold**, which is a display
convention for picking out the largest changes and plays no part in the test.

The expression filter keeps genes above 1 CPM in three of the four libraries.
With two replicates per group this is stricter than edgeR's `filterByExpr()`,
which would size its threshold to the smaller group.
`scripts/03_qc/filter_sensitivity.R` runs both: the gene universe changes from
8,831 to 7,836 and the DE count from 151 to 159, but **all eight *ftm* genes
survive either filter** and their fold changes agree to within 0.06 log₂ units,
so the conclusion does not rest on the choice.

## The pre-specified cluster

The *ftm* cluster was the hypothesis of the experiment, not a discovery from a
genome-wide screen, so correcting its eight *P* values against ~8,800 genes
penalises tests that were never asked.

| Gene | Locus | log₂FC | raw *P* | FDR, genome-wide | FDR, within the cluster |
|---|---|---|---|---|---|
| *ftmA* | PMG11_03146 | −6.92 | 4.9 × 10⁻⁵ | **0.024** | **0.00040** |
| *ftmB* | PMG11_03149 | −6.32 | 5.1 × 10⁻⁴ | **0.038** | **0.00101** |
| *ftmC* | PMG11_03147 | −5.11 | 8.8 × 10⁻⁴ | **0.050** | **0.00141** |
| *ftmD* | PMG11_03148 | −6.10 | 3.5 × 10⁻⁴ | **0.034** | **0.00101** |
| *ftmE* | PMG11_03150 | −5.47 | 4.8 × 10⁻⁴ | **0.037** | **0.00101** |
| *ftmF* | PMG11_03151 | **−8.30** | 1.2 × 10⁻³ | 0.061 | **0.00160** |
| *ftmG* | PMG11_03152 | −5.87 | 2.7 × 10⁻³ | 0.092 | **0.00307** |
| *ftmH* | PMG11_03153 | −4.62 | 6.5 × 10⁻³ | 0.156 | **0.00648** |

Same data, same *P* values — 4 / 8 versus 8 / 8, depending only on what the
correction is applied over. All eight reach *P* < 0.05 uncorrected.

Cluster-level tests, which ask about the set rather than about single genes:

- **The primary, pre-specified test** is `roast` on the eight *ftm* genes,
  99,999 rotations: **P = 0.024** downward, active proportion 1.00, i.e. all
  eight genes move in the same direction. One hypothesis, fixed before the data
  were seen, so this *P* value needs no correction.
- Everything else is **exploratory** and reported for context only. `fry` across
  all gene sets gives Verruculogen P = 0.041 down, RiPP P = 0.0022 up and
  Terpene P = 0.033 up; these sets were not hypotheses of the experiment.

**Iron uptake is not significant in this design** (`roast` upward P = 0.114,
`fry` P = 0.21). The iron-competition model predicts that it should rise, and
with two replicates per group this test has little power, so its absence here is
weak evidence either way and should not be reported as support.

## Known limitation

The libraries are mixed fungal/bacterial and the fungal share differs between
the groups (57.8 % and 77.8 % in the wild-type co-cultures against 19.3 % and
18.6 % in the knock-out co-cultures). TMM normalises the composition of the
fungal library and **cannot** correct a difference in the fungal-to-bacterial
biomass ratio, so a contribution of differing fungal biomass to the signal
cannot be excluded from RNA-seq alone.

`scripts/03_qc/qc_bacterial_load.R` quantifies this and also explains why the
comparison it prints is **descriptive rather than a hypothesis test**: the
fungal read fraction is a property of a mixed library rather than a measurement
of biomass; the rank test treats genes as independent when the eight *ftm* genes
are one co-regulated cluster; and the background set is matched on the observed
|log₂FC|, which is itself a function of the group difference being probed.

Adding the fungal fraction as a covariate is not a fix either: it is nearly
collinear with the group, and if bacillibactin restricts fungal growth then the
lower fungal fraction is part of the biological effect — a mediator, not a
confounder.

Resolving it requires experiments, in this order of priority:

1. **qRT-PCR** for *ftmA*, *ftmE*, *ftmF* normalised to a fungal housekeeping
   gene (β-tubulin, actin, GAPDH) — numerator and denominator are both fungal,
   so the measurement is insensitive to the ratio.
2. **Direct biomass measurement**, by dry weight or qPCR of fungal ITS against
   bacterial 16S.
3. **LC-MS quantification of verruculogen**, the endpoint the transcriptional
   data are being used to predict.

## Reference genome and software

*P. brasilianum* MG11, `GCA_001048715.1` (Pbras_Allpaths-LG), 11,432 genes.
kallisto 0.50.1; R 4.3.3 with limma 3.58.1 and edgeR 4.0.16; Python 3.11.

session the published results came from.
